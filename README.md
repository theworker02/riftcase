# riftcase

Rift validation gates for case inputs before they hit prod.

**Site:** https://theworker02.github.io/riftcase/

## Install / run

```bash
git clone https://github.com/theworker02/riftcase.git
cd riftcase
node src/cli.js
node --test
```
